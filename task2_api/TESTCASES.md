# Тест-кейсы для API

## 1. Создание объявления (test_create_ad)

**Вид теста:** позитивный тест

**Цель:** Проверить, что объявление успешно создается.

**Предусловия:** Сгенерирован случайный sellerId в диапазоне 111111–999999.

**Шаги:**
1. Отправить POST-запрос на `/api/1/item` с телом:
   - sellerId = случайное число
   - name = "Пушистый кот"
   - price = 5000
   - statistics = {"likes": 0, "viewCount": 0, "contacts": 0}

**Ожидаемый результат:**
- Статус-код ответа: 200
- В ответе присутствует поле `id`
- Поля `name` и `price` соответствуют отправленным

---

## 2. Получение объявления по ID (test_get_ad_by_id)

**Вид теста:** позитивный тест

**Цель:** Проверить, что созданное объявление можно найти по его уникальному идентификатору.

**Предусловия:** Создано объявление через fixture `create_ad`.

**Шаги:**
1. Получить ID созданного объявления
2. Отправить GET-запрос на `/api/1/item/{id}`

**Ожидаемый результат:**
- Статус-код ответа: 200
- В ответе содержатся данные объявления
- `id` и `sellerId` совпадают с созданными

---

## 7. Идемпотентность создания (test_create_ad_idempotency)

**Вид теста:** негативный тест

**Цель:** Проверить, что два одинаковых запроса на создание создают два разных объявления (с разными ID).

**Шаги:**
1. Отправить POST-запрос на `/api/1/item` с валидными данными
2. Отправить **такой же** POST-запрос ещё раз
3. Сравнить ID из первого и второго ответа

**Ожидаемый результат:**
- Оба запроса вернули статус 200
- ID из первого и второго ответа **разные**
