# Найденные баги API

## Баг №1: Создание объявления возвращает 504 Gateway Timeout

**Краткое описание:**  
При отправке POST-запроса на создание объявления сервер возвращает ошибку 504 (Gateway Timeout) вместо 200 OK.

**Шаги воспроизведения:**
1. Отправить POST-запрос на `https://qa-internship.avito.com/api/1/item`
2. Тело запроса: валидные sellerId, name, price, statistics

**Фактический результат:**  
Статус-код 504 Gateway Timeout

**Ожидаемый результат:**  
Статус-код 200 OK, объявление создано

**Серьёзность:** P1 (высокий) — блокирует создание объявления

**Окружение:**  
- URL: https://qa-internship.avito.com
- Метод: POST /api/1/item

---

## Баг №2: Получение объявления по ID возвращает 400

**Краткое описание:**  
После создания объявления запрос на его получение по ID возвращает 400 Bad Request.

**Шаги воспроизведения:**
1. Создать объявление
2. Отправить GET-запрос на `/api/1/item/{id}`

**Фактический результат:**  
Статус-код 400

**Ожидаемый результат:**  
Статус-код 200, данные объявления

**Серьёзность:** P1 (высокий) — нельзя получить созданное объявление

**Окружение:**  
- URL: https://qa-internship.avito.com
- Метод: GET /api/1/item/{id}

---

## Баг №4: Создание без sellerId возвращает 504 вместо 400/500

**Краткое описание:**  
При попытке создать объявление без поля sellerId сервер возвращает 504 Gateway Timeout, хотя ожидается ошибка 400 или 500.

**Шаги воспроизведения:**
1. Отправить POST-запрос на `/api/1/item`
2. Тело запроса не содержит поле sellerId

**Фактический результат:**  
Статус-код 504 Gateway Timeout

**Ожидаемый результат:**  
Статус-код 400 (Bad Request) или 500 (Internal Server Error)

**Серьёзность:** P1 (высокий) — неправильная обработка ошибки

**Окружение:**  
- URL: https://qa-internship.avito.com
- Метод: POST /api/1/item

---

## Баг №5: Идемпотентность — первый запрос возвращает 400

**Краткое описание:**  
При проверке идемпотентности первый же запрос на создание объявления возвращает 400, из-за чего тест не может проверить создание двух разных ID.

**Шаги воспроизведения:**
1. Отправить POST-запрос на `/api/1/item` с валидными данными
2. Отправить такой же запрос ещё раз

**Фактический результат:**  
Первый запрос возвращает 400, второй даже не проверяется

**Ожидаемый результат:**  
Оба запроса возвращают 200, ID разные

**Серьёзность:** P1 (высокий)

**Окружение:**  
- URL: https://qa-internship.avito.com
- Метод: POST /api/1/item

---

## Примечание

Тесты **PASSED** показывают, что сервер корректно обрабатывает:
- пустое имя
- отрицательную цену
- нулевую цену
- огромную цену
- длинное имя
- отсутствие полей name, price, statistics

Проблемы связаны с **перегрузкой сервера (504)** и **нестабильной работой (400)** при создании и получении объявлений.
